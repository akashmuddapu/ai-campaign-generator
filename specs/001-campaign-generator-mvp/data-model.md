# Data Model: CampaignGuard AI MVP

**Feature**: `001-campaign-generator-mvp`  
**Date**: 2026-11-18  
**Status**: Completed  

This document defines the data models, attributes, constraints, relationships, and persistence schemas for the CampaignGuard AI platform.

---

## Entity Relationship Overview

```
[User] 1 ──── N [BrandKit] 1 ──── N [Persona]
                   │                   │
                   ▼                   ▼
           [CampaignBundle] ◄─── [PersonaDNA]
                   │
                   ├─── 1 ──── N [CampaignConcept] (Chosen concept selected)
                   │
                   └─── 1 ──── N [CampaignAsset]
                                       │
                                       ├─── 1 ──── 1 [BrandGuardianReport]
                                       └─── 1 ──── 1 [WhyThisContent]
```

---

## Entity Definitions

### 1. User
Represents an authenticated account holder.

| Field | Type | Required | Constraints / Validation | Description |
|---|---|---|---|---|
| `id` | string (UUIDv4) | Yes | Unique | Primary identifier |
| `email` | string | Yes | Valid email format, lowercase, unique | User login credential |
| `password_hash` | string | Yes | Scrypt / PBKDF2 hash string | Salted password hash |
| `name` | string | Yes | Min 2, max 100 chars | Display name |
| `created_at` | string (ISO-8601) | Yes | Standard timestamp | Account registration time |
| `last_login` | string (ISO-8601) | No | Standard timestamp | Last authenticated timestamp |

---

### 2. BrandKit
Represents a company or product brand profile and compliance rules.

| Field | Type | Required | Constraints / Validation | Description |
|---|---|---|---|---|
| `id` | string (UUIDv4) | Yes | Unique | Brand Kit identifier |
| `user_id` | string (UUIDv4) | Yes | Foreign key to User | Owner account |
| `product_name` | string | Yes | Min 2, max 100 chars | Name of product/service |
| `product_description` | string | Yes | Min 10, max 2000 chars | Core product summary |
| `brand_tone` | string | Yes | One of: Authoritative, Bold, Friendly, Witty, Elegant, Educational | Target brand personality |
| `tagline` | string | No | Max 150 chars | Official brand slogan |
| `banned_words` | list[string] | No | Words/phrases to strictly forbid | Deterministic rule filter |
| `example_brand_lines` | list[string] | No | Approved reference copy | Tone reference examples |
| `created_at` | string (ISO-8601) | Yes | Standard timestamp | Creation timestamp |

---

### 3. Customer Persona
Represents a targeted audience segment profile.

| Field | Type | Required | Constraints / Validation | Description |
|---|---|---|---|---|
| `id` | string (UUIDv4) | Yes | Unique | Persona identifier |
| `brand_kit_id` | string (UUIDv4) | Yes | Foreign key to BrandKit | Associated Brand Kit |
| `user_id` | string (UUIDv4) | Yes | Foreign key to User | Owner account |
| `persona_name` | string | Yes | Min 2, max 100 chars | E.g. "Enterprise CISO", "Startup Founder" |
| `primary_goals` | list[string] | Yes | At least 1 goal | What the persona seeks to achieve |
| `pain_points` | list[string] | Yes | At least 1 pain point | Core frustrations & obstacles |
| `core_motivations` | list[string] | Yes | At least 1 motivation | Underlying career/personal drivers |
| `emotional_triggers` | list[string] | Yes | E.g. fear of downtime, desire for speed | Psychological triggers |
| `preferred_message_style` | string | Yes | Concise, Data-Driven, Story-Driven, Punchy | Channel communication preference |
| `buying_triggers` | list[string] | Yes | ROI proof, peer recommendations | What causes conversion |

---

### 4. PersonaDNA (Audience Strategy)
Synthesized tactical communication strategy generated by AI for a persona.

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | string (UUIDv4) | Yes | Strategy identifier |
| `persona_id` | string (UUIDv4) | Yes | Target persona |
| `core_psychological_driver` | string | Yes | Primary emotional anchor |
| `recommended_value_angle` | string | Yes | Differentiated positioning angle |
| `tone_vector` | string | Yes | Adjusted tone guidance for this audience |
| `messaging_hooks` | list[string] | Yes | High-resonance talking points (3-5 items) |
| `anti_patterns` | list[string] | Yes | Words/approaches to avoid for this audience |

---

### 5. CampaignConcept
A high-level conceptual angle for a campaign.

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | string (UUIDv4) | Yes | Concept identifier |
| `title` | string | Yes | Creative campaign title |
| `strategic_theme` | string | Yes | The strategic idea (e.g., "The Frictionless Shift") |
| `creative_hook` | string | Yes | The opening line / headline concept |
| `persona_rationale` | string | Yes | Why this concept appeals to the target persona |

---

### 6. CampaignAsset
Specific marketing collateral generated for a selected concept.

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | string (UUIDv4) | Yes | Asset identifier |
| `concept_id` | string (UUIDv4) | Yes | Chosen concept |
| `channel_type` | string | Yes | `social_post` or `email` |
| `content` | object | Yes | Formatted content object (see sub-schemas below) |
| `created_at` | string (ISO-8601) | Yes | Generation timestamp |

**Social Post Content Object**:
- `headline`: string
- `body`: string (max 280 characters for strict compliance)
- `hashtags`: list[string]
- `visual_suggestion`: string (AI image prompt suggestion)

**Marketing Email Content Object**:
- `subject_line`: string (max 60 characters for strict compliance)
- `preview_text`: string (max 100 characters)
- `body`: string (75–250 words for strict compliance)
- `call_to_action`: string (button text / link copy)

---

### 7. BrandGuardianReport
Automated validation, scoring, and diagnostic report for an asset.

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | string (UUIDv4) | Yes | Report identifier |
| `asset_id` | string (UUIDv4) | Yes | Target asset |
| `overall_score` | integer | Yes | 0 to 100 aggregate score |
| `status` | string | Yes | `pass` (>=85), `warning` (70-84), `fail` (<70) |
| `dimensions` | object | Yes | Breakdown of 6 dimensions (scores + status) |
| `violations` | list[object] | Yes | Itemized rule violations with rule, message, severity |
| `diagnostic_reasoning`| string | Yes | Plain-language evaluation of strengths & weaknesses |

**Dimensions Object**:
- `brand_fit`: `{ score: int, status: str, feedback: str }`
- `persona_fit`: `{ score: int, status: str, feedback: str }`
- `channel_fit`: `{ score: int, status: str, feedback: str }`
- `rule_compliance`: `{ score: int, status: str, feedback: str }`
- `length_check`: `{ passed: bool, current: int, limit: int, unit: "chars"|"words" }`
- `banned_words_check`: `{ passed: bool, flagged_words: list[str] }`

---

### 8. WhyThisContent
Explainability breakdown for non-technical stakeholders.

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | string (UUIDv4) | Yes | Explanation identifier |
| `asset_id` | string (UUIDv4) | Yes | Target asset |
| `persona_reasoning` | string | Yes | Why this messaging hook resonates with persona pain points |
| `brand_reasoning` | string | Yes | How the vocabulary and pacing embody the Brand Tone |
| `channel_reasoning` | string | Yes | Why this structure and CTA maximize channel conversion |

---
